
## Install VirtualBox

### Recommended resources for this walkthrough

For this walkthrough with [VirtualBox](https://www.virtualbox.org/wiki/End-user_documentation) and [Ubuntu Desktop](https://ubuntu.com/download/desktop), use these resource recommendations. They are not vendor minimum requirements.

| Item | Recommendation |
|---|---|
| CPU | dual core CPU |
| RAM | 16GB (the walkthrough below allocates 8GB to the guest VM, so the host needs headroom on top of that) |
| Storage | 30GB |
| Network Connectivity | access to public internet |

### Download VirtualBox

Download and install [VirtualBox](https://www.virtualbox.org/wiki/Downloads) on your machine.
