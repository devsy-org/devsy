A provider tells Devsy where to run workspaces: your machine, a cloud, Kubernetes or an SSH host. Each provider is defined in a `provider.yaml` file that declares its options, binaries and commands.

To use one, see [Manage providers](./manage-providers.mdx). To build one, see [How to develop a provider](../developing-providers/quickstart.mdx).

## Provider types

- **Machine providers** create a VM for the workspace, run the container on it, and start, stop, and delete the VM as needed. AWS is an example.
- **Non-machine providers** run the container directly on the target. Docker, Podman, Kubernetes, and SSH are examples.
