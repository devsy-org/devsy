The desktop app and the CLI do the same things. Use the desktop app for a UI and the CLI for scripts.

Install one, then follow the [Quick Start](./quickstart.mdx).

## Install Devsy Desktop

Download the build for your platform:

- [macOS Silicon/ARM](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_mac_arm64.dmg)
- [macOS Intel/AMD](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_mac_x64.dmg)
- [Windows](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_win_x64.exe)
- [Linux AppImage](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_x86_64.AppImage)
- [Linux DEB (Debian/Ubuntu)](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_amd64.deb)
- [Linux RPM (Fedora/RHEL/openSUSE)](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_x86_64.rpm)
- [Linux Flatpak](https://github.com/devsy-org/devsy/releases/latest/download/Devsy.flatpak)

For earlier versions, see the [GitHub releases page](https://github.com/devsy-org/devsy/releases).

<Callout title="Linux">
The DEB and RPM packages declare their dependencies. The AppImage and Flatpak bundle theirs. If the AppImage does not start, install FUSE 2 (`libfuse2` on Debian and Ubuntu) and try again.
</Callout>

For an AppImage, move it to a permanent location and make it executable. On its first direct launch, Devsy offers **Add to applications**, which creates a user-local launcher. You can decline and add it later under **Settings > Applications menu**.

If you move the AppImage, start it once from the new location. Devsy updates the launcher it owns, unless you edited it. **Settings > Applications menu > Remove** deletes only an unedited launcher and its icon. Devsy never overwrites a system, Flatpak, user-managed, or third-party AppImage launcher, and it leaves another package's default `devsy://` handler alone.

Flatpak, DEB, and RPM packages install their own launchers. If a running window shows a generic icon, see [Linux icon troubleshooting](/docs/troubleshooting/linux-troubleshooting#generic-application-icon-on-gnome).

<Callout title="Windows dependency">
If the app does not open, install [WebView 2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/?form=MA13LH). Recent versions of Windows include it.
</Callout>

## Install Devsy CLI

On macOS or Linux, run the install script:

```bash
curl -L https://devsy.sh/install.sh | sh
```

The script:

- Downloads the latest CLI for your OS and architecture from [GitHub releases](https://github.com/devsy-org/devsy/releases).
- Verifies the SHA-256 checksum when a checksum entry and `sha256sum` or `shasum` are available.
- Installs `devsy` into `/usr/local/bin`. If that directory is not writable and `sudo` is missing, it installs into `~/.local/bin`.

Run it again to update. On Windows, use the PowerShell command in the Windows tab below.

Two environment variables change the script:

- `DEVSY_VERSION` installs a specific release instead of the latest: `curl -L https://devsy.sh/install.sh | DEVSY_VERSION=vX.Y.Z sh`
- `DEVSY_INSTALL_DIR` installs to another directory: `curl -L https://devsy.sh/install.sh | DEVSY_INSTALL_DIR="$HOME/bin" sh`

On macOS or Linux, you can also use [Homebrew](https://brew.sh):

```bash
brew install devsy-org/homebrew-tap/devsy
```

Upgrade later with `brew upgrade devsy`.

To download a binary directly, use the command for your platform below.
