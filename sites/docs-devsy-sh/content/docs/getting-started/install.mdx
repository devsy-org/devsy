Devsy comes as a desktop app and a CLI. Both do the same things. Use the desktop app if you want a UI and the CLI for scripting.

Install one, then follow the [Quick Start](./quickstart.mdx).

## Install Devsy Desktop

Download the build for your platform:

- [macOS Silicon/ARM](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_mac_arm64.dmg)
- [macOS Intel/AMD](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_mac_x64.dmg)
- [Windows](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_win_x64.exe)
- [Linux AppImage](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_x86_64.AppImage)
- [Linux DEB (Debian/Ubuntu)](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_amd64.deb)
- [Linux RPM (Fedora/RHEL/openSUSE)](https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_x86_64.rpm)
- [Linux Flatpak](https://github.com/devsy-org/devsy/releases/latest/download/Devsy.flatpak)

For earlier versions, see the [GitHub releases page](https://github.com/devsy-org/devsy/releases).

<Callout title="Linux">
The DEB and RPM packages declare their dependencies, and the AppImage and Flatpak bundle theirs. If the AppImage does not start, install FUSE 2 (`libfuse2` on Debian and Ubuntu) and try again.
</Callout>

For an AppImage, first move it to a permanent location and make it executable. On its first direct launch, Devsy offers **Add to applications**. This creates a user-local launcher and copies its icon outside the temporary AppImage mount. You can decline and add it later under **Settings > Applications menu**.

If you move the AppImage later, start it once from its new location; Devsy updates a launcher it owns. **Settings > Applications menu > Remove** removes only that launcher and its owned icon. Devsy does not overwrite an existing system, Flatpak, user-managed or third-party AppImage launcher, or change another package's default `devsy://` handler.

Flatpak, DEB and RPM packages install their own launchers; the AppImage action is not used for those formats. See [Linux icon troubleshooting](/docs/troubleshooting/linux-troubleshooting#generic-application-icon-on-gnome) if a running window still shows a generic icon.

<Callout title="Windows dependency">
If the app does not open, install [WebView 2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/?form=MA13LH). Recent versions of Windows include it.
</Callout>

## Install Devsy CLI

On macOS or Linux, the quickest option is the install script:

```bash
curl -L https://devsy.sh/install.sh | sh
```

The script:

- Downloads the latest CLI for your OS and architecture from [GitHub releases](https://github.com/devsy-org/devsy/releases).
- Verifies the SHA-256 checksum when a checksum entry and `sha256sum` or `shasum` are available.
- Installs `devsy` into `/usr/local/bin`, or into `~/.local/bin` if it cannot write there and `sudo` is not available.

Run it again to update. On Windows, use the PowerShell command in the Windows tab below.

Two environment variables customize the script:

- `DEVSY_VERSION` installs a specific release instead of the latest: `curl -L https://devsy.sh/install.sh | DEVSY_VERSION=vX.Y.Z sh`
- `DEVSY_INSTALL_DIR` installs somewhere other than the default: `curl -L https://devsy.sh/install.sh | DEVSY_INSTALL_DIR="$HOME/bin" sh`

On macOS or Linux, you can also install with [Homebrew](https://brew.sh):

```bash
brew install devsy-org/homebrew-tap/devsy
```

Upgrade later with `brew upgrade devsy`.

To download a binary yourself, use the command for your platform below.

