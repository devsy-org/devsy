## Create a machine

Create a new machine with:

```sh
devsy machine create <name-of-machine> --provider <provider-name>
```

List all machines:

```sh
devsy machine list
```

Example output:

```
  NAME | PROVIDER | AGE
-------+----------+------
  <name-of-machine> | aws      | 21s
```

Check the state of a machine:

```sh
devsy machine status <name-of-machine>
```

Example output:

```
08:48:58 info Machine '<name-of-machine>' is 'Running'
```

## SSH into a machine

Open an SSH session directly to the machine:

```sh
devsy machine ssh <name-of-machine>
```

## Describe a machine

Retrieve the provider-generated description of a machine (the same text-based summary the provider itself reports):

```sh
devsy machine describe <name-of-machine>
```

## Inspect a machine

Print the machine's full configuration as JSON, including its provider and provider options. Sensitive options are redacted and hidden options are omitted:

```sh
devsy machine inspect <name-of-machine>
```

## Stop a machine

Stop a machine with:

```sh
devsy machine stop <name-of-machine>
```

Check the status afterwards:

```sh
devsy machine status <name-of-machine>
```

Example output:

```
08:58:58 info Machine '<name-of-machine>' is 'Stopped, you can start it via 'devsy machine start <name-of-machine>''
```

## Start a machine

Restart a stopped machine with:

```sh
devsy machine start <name-of-machine>
```

## Delete a machine

Delete a machine with:

```sh
devsy machine delete <name-of-machine>
```

<Callout type="warn">
This is non-reversible. All workspace containers and data on the machine are lost.
</Callout>
