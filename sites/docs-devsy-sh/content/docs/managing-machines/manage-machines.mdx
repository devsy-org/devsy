A machine is a server that a provider creates. See [What are machines](./what-are-machines.mdx). Run `devsy machine --help` to list all commands.

## Create and list

```sh
devsy machine create <name> --provider <provider-name>
devsy machine list
```

## Check and inspect

```sh
devsy machine status <name>
devsy machine describe <name>
devsy machine inspect <name>
```

`describe` prints the provider's summary. `inspect` prints the machine configuration as JSON. Sensitive options are redacted, and hidden options are left out.

## Connect

```sh
devsy machine ssh <name>
```

## Stop, start, delete

```sh
devsy machine stop <name>
devsy machine start <name>
devsy machine delete <name>
```

<Callout type="warn">
Deleting a machine cannot be undone. You lose all workspace containers and data on it.
</Callout>
