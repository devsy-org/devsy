## Install Minikube on Ubuntu 22.04

Install the packages for Minikube and VS Code:
```sh
sudo apt update
sudo apt install git vim gpg wget -y
```

### Install VSCODE

Follow the [VS Code Linux setup guide](https://code.visualstudio.com/docs/setup/linux).

### Install Minikube

Clone Sander van Vugt's CKAD repository from the [Installing Minikube on Ubuntu](https://learning.oreilly.com/videos/certified-kubernetes-application/9780137841509/9780137841509-CKAD_01_04_03/) lesson:

```sh
git clone https://github.com/sandervanvugt/ckad.git
cd ./ckad
./minikube-docker-setup.sh
```

#### Create startup script

```sh
cd ~
touch minikube-start.sh
sudo chmod u+x minikube-start.sh
```

Add the following contents to minikube-start.sh:

```bash
#!/bin/bash

minikube start --driver=docker --cni=calico
```

Start Minikube from your home directory:

```sh
~/minikube-start.sh
```

Run the script again after each VM shutdown or reboot.

#### Test your install

Check the install:
```sh
kubectl get all
```

Expected output:
```sh
kubectl get all
NAME                 TYPE        CLUSTER-IP   EXTERNAL-IP   PORT(S)   AGE
service/kubernetes   ClusterIP   10.96.0.1        <none>        443/TCP   4d14h
```

## Install Devsy

Download and install the Linux DEB package, as described in [Install Devsy](../getting-started/install.mdx):

```sh
cd ~/
wget https://github.com/devsy-org/devsy/releases/latest/download/Devsy_linux_amd64.deb
sudo dpkg -i Devsy_linux_amd64.deb
```

### Test the Devsy install

Start Devsy:

```sh
devsy
```

## Configure Minikube for the provider

Before you configure the Kubernetes provider, create a persistent volume for the devcontainer and find a kubeconfig.

### Create a Kubernetes persistent volume for devcontainers

See the [Kubernetes persistent volume docs](https://kubernetes.io/docs/concepts/storage/persistent-volumes/).

```
mkdir ~/devsys
cd ~/devsys
touch devsy-pv.yml
vim devsy-pv.yml # or your preferred text editor
```

Edit `devsy-pv.yml` and save it:
```yaml
kind: PersistentVolume
apiVersion: v1
metadata:
  name: devsy-pv
  labels:
    type: devsy
spec:
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteOnce
  hostPath:
    path: "/mnt/data/devsy"
```

The `hostPath` directory must exist inside the Minikube node, not on your host machine. Create it with `minikube ssh`:

```sh
minikube ssh -- sudo mkdir -p /mnt/data/devsy
```

Create the persistent volume:

```sh
kubectl create -f ~/devsys/devsy-pv.yml
```

Confirm that the volume exists:

```sh
kubectl get pv
NAME                                       CAPACITY   ACCESS MODES   RECLAIM POLICY   STATUS      CLAIM   STORAGECLASS   REASON   AGE
devsy-pv                                  1Gi        RWO            Retain           Available                                   12d
```

### Locate your kubeconfig

List the `~/.kube` directory:

```sh
ls ~/.kube
cache  completion.bash.inc  config
```

The `config` file in `~/.kube` is the kubeconfig for the Kubernetes provider. Print its absolute path and use the output when configuring the provider:

```sh
echo ~/.kube/config
```

In production, give the kubeconfig a specific context, namespace, and user. Install kubectl on the machine where the Devsy client runs, because the Kubernetes provider runs kubectl with the local kubeconfig to reach a remote cluster.

### Identify your namespaces

The Kubernetes provider needs a namespace. This example uses `default`.

```sh
kubectl get ns
NAME              STATUS   AGE
default           Active   12d
kube-node-lease   Active   12d
kube-public       Active   12d
kube-system       Active   12d
```

## Add Provider

Go to **Providers** > **+ Add** and select the Kubernetes provider.

### Configure the Kubernetes Provider

| Setting | Value |
|---|---|
| Kubernetes Namespace | default |
| Disk Size | 1Gi |
| Kubernetes Config | The absolute path printed by `echo ~/.kube/config` |

Select **Add Provider**

### Add a Workspace

#### Start a workspace with VS Code Browser

Go to **Workspaces** > **+ Create**. Enter your project URL or pick one of the quickstart examples. Under **Default IDE**, select **VS Code Browser**.

Click **Create Workspace**.

Devsy shows the workspace starting in a new window. When the workspace is ready, VS Code opens connected to the devcontainer.
